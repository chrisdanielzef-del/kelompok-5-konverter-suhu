Konverter Suhu Sederhana

Pendahuluan: Program Konverter Suhu Sederhana adalah sebuah aplikasi berbasis Python yang dirancang untuk membantu pengguna melakukan konversi suhu antar tiga satuan utama, yaitu Celsius, Fahrenheit, dan Kelvin. Program ini dibuat dengan tujuan memberikan kemudahan dalam menghitung perubahan suhu tanpa harus melakukan perhitungan manual. Dengan antarmuka berbasis teks yang sederhana, pengguna dapat memilih jenis konversi yang diinginkan dan langsung mendapatkan hasil dengan cepat dan akurat.

Fitur Utama:

Konversi dari Celsius ke Fahrenheit

Konversi dari Celsius ke Kelvin

Konversi dari Fahrenheit ke Celsius

Konversi dari Fahrenheit ke Kelvin

Konversi dari Kelvin ke Celsius

Konversi dari Kelvin ke Fahrenheit

Hasil konversi ditampilkan dengan format dua angka di belakang koma untuk meningkatkan keterbacaan.

Program sederhana, ringan, dan tidak membutuhkan library tambahan.

Panduan Instalasi:

Pastikan Python versi 3.x sudah terpasang di komputer Anda.

Unduh repository program ini dengan perintah: git clone https://github.com/username/konverter-suhu.git

Masuk ke folder hasil unduhan: cd konverter-suhu

Tidak diperlukan instalasi library tambahan karena program hanya menggunakan fungsi bawaan Python.
