Judul:
Konverter Suhu Sederhana

Pendahuluan:
Program Konverter Suhu Sederhana adalah sebuah aplikasi berbasis Python yang dirancang untuk membantu pengguna melakukan konversi suhu antar tiga satuan utama, yaitu Celsius, Fahrenheit, dan Kelvin. Program ini dibuat dengan tujuan memberikan kemudahan dalam menghitung perubahan suhu tanpa harus melakukan perhitungan manual. Dengan antarmuka berbasis teks yang sederhana, pengguna dapat memilih jenis konversi yang diinginkan dan langsung mendapatkan hasil dengan cepat dan akurat.

Fitur Utama:
-Konversi dari Celsius ke Fahrenheit
-Konversi dari Celsius ke Kelvin
-Konversi dari Fahrenheit ke Celsius
-Konversi dari Fahrenheit ke Kelvin
-Konversi dari Kelvin ke Celsius
-Konversi dari Kelvin ke Fahrenheit

Hasil konversi ditampilkan dengan format dua angka di belakang koma untuk meningkatkan keterbacaan.
Program sederhana, ringan, dan tidak membutuhkan library tambahan.

Panduan Instalasi:
Pastikan Python versi 3.x sudah terpasang di komputer Anda.

Unduh repository program ini dengan perintah: git clone https://github.com/chrisdanielzef-del/kelompok-5-konverter-suhu.git

Masuk ke folder hasil unduhan: cd konverter-suhu

Tidak diperlukan instalasi library tambahan karena program hanya menggunakan fungsi bawaan Python.

Panduan Menjalankan:  
1. Buka terminal atau command prompt.  
2. Jalankan program dengan perintah:  
   bagian4.py  
3. Program akan menampilkan menu pilihan konversi suhu (1–6).  
4. Masukkan angka sesuai jenis konversi yang diinginkan.  
5. Masukkan nilai suhu yang ingin dikonversi.  
6. Program akan menampilkan hasil konversi sesuai pilihan.

Dokumentasi Teknis:  
Program ini menggunakan struktur fungsi sederhana untuk setiap jenis konversi suhu. Setiap fungsi menerima input berupa nilai suhu dan mengembalikan hasil konversi sesuai rumus standar.  

Flowchart Sistem:  

Mulai Program  
↓  
Tampilkan Menu Pilihan  
↓  
Input Pilihan (1–6)  
↓  
Input Nilai Suhu  
↓  
Proses Konversi Suhu (memanggil fungsi sesuai pilihan)  
↓  
Tampilkan Hasil Konversi  
↓  
Selesai  


Contoh Output Program

===== KONVERTER SUHU SEDERHANA =====
1. Celsius → Fahrenheit
2. Celsius → Kelvin
3. Fahrenheit → Celsius
4. Fahrenheit → Kelvin
5. Kelvin → Celsius
6. Kelvin → Fahrenheit

Pilih jenis konversi: 1
Masukkan nilai suhu: 25
Hasil: 25.00°C = 77.00°F


Penjelasan:  
- Program dimulai dengan menampilkan menu konversi.  
- Pengguna memilih jenis konversi dengan memasukkan angka 1–6.  
- Pengguna memasukkan nilai suhu yang ingin dikonversi.  
- Program memanggil fungsi konversi sesuai pilihan.  
- Hasil konversi ditampilkan dengan format dua angka di belakang koma.  
- Program selesai setelah hasil ditampilkan.
